Spotify неожиданно выложила плагины, которые сокращают расход токенов в Claude Code на 90% 😱

Первый, Portal, позволяет Claude Code отдавать легкие задачи дешёвым моделям вроде Gemini 2.5 Flash. А второй, Shunt, автоматизирует этот процесс.

Так, если Claude пытается прочитать файл больше 350 строк, то Shunt остановит его и через Portal отдаст файл дешёвой модели, которая вернет резюме. А сложные задачи, где реально нужны рассуждения, остаются Claude.

У автора этот подход сократил расход токенов на чтение файлов примерно на 90%.

ЧТО: OpenAI заявила, что решила одну из семи задач тысячелетия — проблему Навье—Стокса 🤯
