Максим Дубинин, Senior Software Engineer с 10-летним опытом вместе с Александром Лепешкиным - экспертом по LinkedIn и Principal Software Program Manager в Zalando - разобрали, как эта система работает изнутри.

На мастер-классе Максим разберет на винтики изнанку системы поиска LinkedIn:

— CV и LinkedIn расходятся = 🚩 для рекрутера
— Responsibilities вместо achievements = нанимающие менеджеры скипают
— Неправильные ключевые слова = алгоритм тебя не видит
— Unicode и жирный шрифт = ATS читает кракозябры и не пропускает

⏰1 апреля 17:30 (Берлин) / 18:30 (GMT+2) Максим и Александр проведут бесплатный живой разбор профилей.
